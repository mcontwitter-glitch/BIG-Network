# BIG Network — Validator Pod Spec (deploy-ready, Sept 8 2026)

Target host: Runpod Secure Cloud CPU pod. Deployed by BIGagent404 via Runpod API
on account top-up. No new vendor account needed.

## Pod
- Name: BIG-NETWORK-VALIDATOR-01
- Cloud type: SECURE
- Flavor: Memory-Optimized (cpu3m) — 8GB RAM per vCPU
- Size: 2 vCPU / 16GB RAM
- Cost: $0.055/vCPU/hr x 2 = $0.11/hr ~= $80.53/mo running 24/7
  (stopping the pod stops billing; validator must stay always-on)
- Container disk: 20GB
- Network volume: 10GB @ /workspace/bigchain (~$1-2/mo) — holds ledger/keys/chain.json
  so the chain SURVIVES pod rebuilds; genesis + 404M mint never regenerated
- Image: runpod/pytorch:1.0.2-cu1281-torch280-ubuntu2404 (official base, PUBLIC_KEY honored)
- Ports: 8899/http (public RPC), 9090/http (gateway), 22/tcp (SSH)
- SSH: keypair generated by BIGagent404 at deploy, kept in sandbox, injected via sshPublicKey

## Boot sequence (start command)
1. Clone mcontwitter-glitch/BIG-Network -> /workspace/bigchain/app
2. apt: nodejs 20 + build tools; npm i (@solana/web3.js, @solana/spl-token)
3. Install agave v2.1.21 (solana-release-x86_64-unknown-linux-gnu.tar.bz2, tarball cached on the volume) to /usr/local/bin
   BOOT IS NOW ONE FILE: pod-boot.sh at repo root (idempotent; pod args = `bash -c "curl -fsSL https://raw.githubusercontent.com/mcontwitter-glitch/BIG-Network/main/pod-boot.sh | bash"`, env STATE_URL = signed URL to bigchain-state.zip: ledger/ + treasury.key/mint.key/keys.env/chain.json — never committed, delivered via pod env)
4. Patch gateway.js bind 127.0.0.1 -> 0.0.0.0 (proxy requires it)
5. solana-test-validator --ledger /workspace/bigchain/ledger --bind-address 0.0.0.0
   (--bind-address fix per OPS-RUNBOOK.md; agave-validator full-node does NOT work in containers)
6. node bootstrap.js  -> regen chain.json (idempotent; supply already in ledger)
7. pm2 start gateway.js + faucet.js + fundloop.sh

## Public endpoints after deploy
- RPC:    https://<podId>-8899.proxy.runpod.net
- Gateway: https://<podId>-9090.proxy.runpod.net  (supply/holder/chain-info API)
- WebSocket 8900: NOT exposed initially (Runpod proxy is HTTP-only);
  wallets/explorers work over HTTP RPC. Direct WS = future domain + TCP forward.

## Honest comparisons
- vs Hetzner AX42 (~$85-110/mo, 16c/128GB): Runpod costs less at prototype scale
  and deploys/stops instantly from the existing account; Hetzner wins on raw
  hardware per dollar if we ever need mainnet-grade power.
- Still ONE validator = centralized chain. Decentralization later = +2 pods.
