Option A — One Command (any server)

Paste this on a fresh Ubuntu/Debian box. The installer does everything: installs the chain, joins the live network, and your node is serving reads in about 3 minutes.

curl -fsSL https://raw.githubusercontent.com/mcontwitter-glitch/BIG-Network/main/install-node.sh | sudo bash

The node catches up from the seed's latest snapshot over HTTP — it works even behind cloud proxies. After boot: RPC reads on port 8899, wallet + BIGscan UI on port 9090.
